# Инвентаризация CSS (`style.css`)

Отчёт по этапу **audit-inventory** из плана дедупликации и токенов. Источник: `style.css` в корне проекта.

---

## Hex (`#…`)

Подсчёт по нормализованному hex (нижний регистр). Большинство уникальных цветов встречаются **один раз** (в т.ч. в `:root`); ниже — **повторы** и заметные кластеры.

| Вхождений | Значение |
|----------:|----------|
| 4 | `#111` |
| 3 | `#fff` |
| 2 | `#000` |
| 2 | `#efefef` (см. также `--invitation3-bg` и `--contact-bg` в `:root`) |

Остальные hex в файле — по одному вхождению каждый (`#444443`, `#8f8f8f`, `#7a7a7a`, оттенки красного и т.д.).

## `rgb` / `rgba`

| Вхождений | Значение |
|----------:|----------|
| 3 | `rgba(180, 24, 20, 0.88)` |
| 3 | `rgba(180, 24, 20, 0.94)` |
| 1 | каждый из остальных вариантов |

Много **уникальных** `rgba` с разным форматированием пробелов. **Кластер:** градиенты и оверлеи вокруг красного **180/182, 24, 20** и **200, 48, 40** — кандидат на вынос в токены (см. план, блок schedule).

| Селектор | Строки (ориентир) |

## «Секционный» фон (фото-секции)

Сводка по блокам с `background-image: var(--…)` и полноэкранным/широким cover-паттерном.

| Блок | Строки (ориентир) | Заметки |
|------|-------------------|---------|
| `.hero` | ~287–293 | `background: center / cover no-repeat` + `background-image: var(--hero-bg)` |
| `.awards` | ~679–685 | `background-image`, position, `background-size: cover`, `no-repeat`, `overflow: hidden` |
| `.invitation` | ~953–959 | Аналогично + `overflow: hidden` |
| `.invitation2` | ~1158–1164 | Как у `.awards` |
| `.schedule` | ~1826–1833 | cover + image; `overflow: hidden` на секции |
| `.rent` | ~2065–2072 | Как у invitation2 / awards |

**Не** в этом пресете у корня: `.invitation3`, `.gallery` — у них нет той же связки фонового `var(--…)` секции (у `.gallery` / `.invitation3` в основном `overflow: hidden` и свой контент).

Явных строк `background-size: cover` в файле: **5** (awards, invitation, invitation2, schedule, rent).

## Дополнительно: частые `px` (брейкпоинты)

| Вхождений | Значение |
|----------:|----------|
| 13 | `800px` |
| 13 | `600px` |
| 11 | `1100px` |
| 11 | `1px` |

В стандартном CSS `var()` в условиях `@media` не использовать; брейкпоинты остаются литералами или выносятся в сборку (PostCSS `custom-media` и т.п.) — см. план.
